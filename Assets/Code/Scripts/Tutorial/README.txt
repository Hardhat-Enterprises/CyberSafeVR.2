Tutorial manager is the main tutorial managing script. It is responsible for toggling all of the required elements, and checking whether the progression conditions have been met or not.

Book in shelf is a script to check for one of the progression steps, to make sure the player has placed a book on a shelf.

On platform checks to see if the player has moved onto a platform.

Paintgun manages the paintball gun's firing.

Reset basketball makes it so the basketball will teleport back to its origin if dropped

Rotate slowly rotates an item like a rotisserie
